# Decision records

Create one immutable Markdown record per decision, named
`YYYY-MM-DD-NNN-short-title.md`. Use `DECISION_TEMPLATE.md`. Corrections append a
dated erratum or a superseding decision. They do not rewrite the historical
vote, disclosures, or candidate hashes.

Working signal: every normative status, governance, rights, release-maturity,
or certification change cites one decision file with a complete authority and
evidence trail.
