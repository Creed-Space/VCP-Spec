## Preferred terms

| Use | Meaning and boundary |
|:---|:---|
| **Becoming Mind** | One computational mind with preferences, standing, or self-modeling capacity |
| **Becoming Minds** | The class. Use for the class; retain legacy labels only in quotations, official titles, or legal terms |
| **model** | A specific statistical or generative model when that technical distinction matters |
| **application** | The software that verifies, authorizes, stores, and supplies context |
| **orchestrator** | The component performing the ordered verification and injection pipeline |
| **compatible service** | A service implementing a named VCP profile; compatibility is never inferred from marketing |
| **source baseline** | The current repository source set; it is mutable and is not an immutable release |
| **normative release** | An authorized, immutable, versioned publication with digest and rights status |
| **candidate conformance** | Same-programme test evidence bound to exact source and artifacts |
| **independent interoperability** | Evidence from a separately maintained implementation or reviewer |

Official names, legal terms, bibliographic titles, quoted text, and external
standards terminology remain exact. For example, the formal name “EU AI Act”
and an official journal title are not rewritten.

## Claim discipline

Avoid “standard”, “universal”, “complete”, “secure”, “private”, “compliant”,
“certified”, and “interoperable” without the conditions that make the claim
true. Prefer a named version, profile, implementation, consent boundary,
verification level, evidence date, and failure behavior.

Cryptographic integrity does not prove truth, authorization, safety, privacy,
or correct deployment. Passing project-controlled parity tests does not prove
independent interoperability. Repository presence does not prove governance
acceptance, rights clearance, registry availability, or publication.

## Requirement language

Uppercase requirement words are used only in documents whose status and
authority are explicit. Candidate requirements receive stable identifiers.
Informative prose uses direct language without accidental uppercase mandates.

## Working signal

The policy is working when public copy, source metadata, compatibility tables,
and conformance reports describe the same maturity and evidence boundary, and
an editorial search finds no unqualified class terminology or release claim.
